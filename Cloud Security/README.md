# 🔐 AWS Cloud Security Practical

## 📌 Project Overview
This project demonstrates basic cloud security implementation using Amazon Web Services (AWS). It focuses on Identity and Access Management (IAM), user groups, permissions, managed policies, and Multi-Factor Authentication (MFA).

## 🎯 Objectives
- Understand cloud security and AWS IAM.
- Create and manage IAM users and user groups.
- Assign permissions using IAM policies.
- Enable Multi-Factor Authentication (MFA).
- Apply the principle of least privilege for secure access management.

## 🛠️ AWS Services Used
- **AWS IAM:** Manages users, groups, roles, and permissions.
- **IAM Policies:** Define permissions for AWS resources.
- **MFA:** Adds an extra layer of authentication.
- **AWS Organizations:** Helps manage multiple AWS accounts centrally.

## ⚙️ Practical Tasks
1. Create an IAM user.
2. Create an IAM user group.
3. Attach managed policies to the group.
4. Add the IAM user to the group.
5. Configure console access for the user.
6. Assign a virtual MFA device.
7. Explore AWS Organizations and its features.
8. Verify IAM permissions and security settings.

## ✅ Result
Successfully explored AWS cloud security features and configured IAM users, groups, permissions, and MFA. These features help control access to AWS resources and improve account security.

## 🔒 Security Best Practices
- Enable MFA for user accounts.
- Follow the principle of least privilege.
- Avoid sharing passwords and access keys.
- Review IAM permissions regularly.
- Never upload credentials, MFA codes, or secret keys to GitHub.

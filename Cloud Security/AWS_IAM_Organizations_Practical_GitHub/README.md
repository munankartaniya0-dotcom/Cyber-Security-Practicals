# AWS IAM and Organizations Practical

## Aim
To explore AWS Identity and Access Management (IAM) and the AWS Organizations console.

## Topics demonstrated
- IAM user and user-group overview
- Permissions policies attached to a group and user
- Multi-factor authentication (MFA) overview
- AWS Organizations landing page and account-management features

## Procedure (summary)
1. Open the AWS Management Console and navigate to **IAM**.
2. Review the **Users** and **User groups** sections.
3. Open the relevant user group and inspect its attached permissions policies.
4. Open the IAM user's **Security credentials** tab and review MFA status.
5. Navigate to **AWS Organizations** and review the overview, benefits, and account-management workflow.

## Result
The IAM user/group pages, policy attachments, MFA section, and AWS Organizations overview were reviewed.
